# 🐍 Python Error Fixing Tool (AI Wrapper)

An AI-powered web app that analyzes Python errors and suggests fixes.

## 🚀 Features

- Detects Python errors
- Explains errors in simple language
- Provides corrected code
- Built with Streamlit + Groq Llama

## 🛠 Tech Stack

- Python
- Streamlit
- Groq API (Llama 3)
- Prompt Engineering

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
